# Brand: intake, strategy, logo directions, boards, token sheets

Sources: Leonxlnx's brandkit (imagegen-skills) and Anthropic's brand-guidelines, reconciled with the Floor and house values in SKILL.md.

A brand kit is a visual argument for why the brand exists, not decoration. Every board answers five questions: what the brand represents, its core metaphor, how the logo expresses it, how the system scales across UI, print, image and detail, and why it feels ownable.

---

## 1. Intake

Decide **new identity or extension** from what the user says, not from whether files are attached. Mood references alone never establish an existing identity.

If unclear, ask **one** short question covering only what is missing: create from scratch, extend, or refresh/rebrand; existing logo or wordmark; colors; fonts; mood references.

| Flow | Do | Don't |
|---|---|---|
| Create from scratch | full flow §2–§9 | |
| Build on an existing brand | reuse the supplied logo, name, colors, type and direction exactly; develop only what is missing | invent replacements, reinterpret the logo |
| Refresh / rebrand | change only the elements in scope; preserve the rest | silently restyle everything |
| Assets referenced but not supplied | request them and wait | guess or redraw them |

Existing identity constraints override every default in this file. Supplied assets are source material to reuse; inspiration references are quality bars to learn from, never to copy (§8).

## 2. Strategy first

Infer before drawing anything: category, audience, product function, emotional promise, cultural position, trust level, visual world, symbolic metaphor, and what to avoid. State the result in 4–6 lines and pick the metaphor from meaning, never at random.

| Category | Core ideas | Symbol logic |
|---|---|---|
| Developer tool | building, speed, precision, control | cursor, frame, scaffold, grid, bolt (only if speed is the claim) |
| AI assistant | delegation, intelligence, clarity | orbit, signal, path, node, handoff (no sparkle or wand: the Floor) |
| Security | protection, vigilance, boundary | shield, eye, seal, protected core |
| Gaming / betting | chance, reward, tension, speed | dice, gem, card, signal, trophy |
| Voice AI | sound, rhythm, command, flow | waveform, mic, orb, speech path |
| Compliance | trust, order, rules, protection | seal, badge, document, shield, guardian animal |
| Drone / robotics | flight, control, vision, mission | wing, owl, crosshair, path, zone |
| Luxury / editorial | taste, material, ritual, restraint | monogram, seal, paper, emboss |
| Productivity | focus, momentum, clarity | path, check, block, calendar, light |

## 3. Logo standard

Only when a new logo is needed or requested. The mark must be simple, memorable, symbolic, scalable, ownable, balanced and tied to the brand idea, and must work as icon, wordmark, badge, UI mark and pattern. It should read as research and reduction.

Avoid: generic lightning bolts without a reason, random animals, fake luxury crests, look-alikes of famous marks, overcomplication, clipart, meaningless sparkles, inconsistent variants.

**Concept methods** (use one, combine at most two):

| Method | How | Examples |
|---|---|---|
| 1. Monogram + meaning | initial fused with the metaphor via negative space, cuts, folds or geometry; never a plain letter in a box | K + kite/frame, N + folded path, S + sound wave, A + ascent |
| 2. Product action | the verb the product performs, abstracted | build → scaffold/block/cursor · protect → shield/boundary · convert → switch/transform · speak → waveform/pulse · hunt threats → eye/radar/trace · automate → loop/handoff |
| 3. Metaphor fusion | two ideas reduced into one readable mark | owl + drone vision, shield + mountain, moon + waveform, cursor + bolt |
| 4. Negative space | a hidden form that rewards a second look; must stay crisp at 16px | hidden arrow, protected center, cutout initial, folded corner |
| 5. Construction geometry | circles, diagonal cuts, grids, modular blocks, orbital paths, measured linework; one panel can show the construction | |

Deliver 3 directions max, each with: method, one-line rationale, the mark at 512px and at 16px, and the wordmark lockup.

## 4. Board composition

One overview board of the whole brand world. Defaults: layout **3×3**, aspect **4:3 or 16:10**, strong consistent gutters, minimal text. Canvas size describes the whole image, not the grid: honor a requested W×H, ratio or orientation, adapt the grid to square, portrait or wide without stretching panels, and report the real output size. Never promise pixels the tool cannot produce.

Panels are not equally loud. Rhythm: quiet → functional → emotional → technical → atmospheric → detailed. One strong brand idea per board; the logo repeats consistently across touchpoints.

**3×3 identity system** (rearrange if the canvas demands it):

| # | Panel | Content |
|---|---|---|
| 1 | Logo cover | large mark + wordmark, minimal title, strong negative space |
| 2 | Construction | grid, geometry or negative-space logic showing why the mark exists (existing logo without construction docs: show its supplied variants) |
| 3 | Digital application | app header, terminal, prompt bar, app icon or dashboard fragment |
| 4 | Brand essence | one short tagline, large readable type |
| 5 | Color system | swatches, strips, discs or chips with role names |
| 6 | Typography | large specimen, alphabet row, heading/body pairing |
| 7 | Physical application | card, folder, badge, poster, label, seal or packaging |
| 8 | Image direction | cinematic landscape, product crop, halftone poster or material texture |
| 9 | System detail | UI chips, input bar, command line, icon row, badge set or pattern |

**2×3 mini-deck:** (1) logo/wordmark, centered or offset, extremely minimal · (2) product surface (app frame, prompt input, URL field) · (3) functional panel (terminal, install command, input state) · (4) atmosphere image · (5) symbol, construction or badge · (6) tagline, one line, large type, quiet background.

Other layouts: `2×2` compact concept board · `1×3` horizontal strip · `4×2` wide contact sheet.

## 5. Visual modes

Pick one from the strategy. A mode sets cues, mark logic and mood; it never overrides an existing identity.

| Mode | For | Cues | Marks | Mood |
|---|---|---|---|---|
| Dark developer / builder | dev tools, coding agents, infra | near-black panels, monospace accents, terminals, prompt bars, subtle grid, one cyan, coral or lime accent, pixel/CRT texture | cursor + frame, scaffold + monogram, terminal glyph, modular construction | precise, builder-native |
| Dark product / operator | growth, sales agents, automation | black with dark red or amber, card systems, segmented flows, progress motifs, minimal hero text | signal, path, switch, loop, operator mark | fast, tactical |
| Dark nature / calm system | strategy, travel, wellness, climate, quiet SaaS | deep green + lime, misty landscapes, soft overlays, dark editorial grid | path, leaf, moon, horizon, compass, folded mark | calm, trustworthy |
| Dark security / threat intel | security | black/navy, shield forms, radar lines, red/blue alert chips | shield, raptor, eye, boundary, protected core | serious, vigilant |
| Light editorial / compliance | legal, privacy, documents | warm ivory, paper texture, small serif labels, seals, deep blue/red/gold | seal, stamp, document, monogram | institutional but modern |
| Luxury / beauty / fashion | beauty, hospitality, premium services | ivory, stone, espresso, serif wordmark, paper grain, embossing, editorial crops | monogram, seal, vessel, typographic mark | tasteful, adult |
| Voice / communication | voice AI, chat, audio | dark indigo, one lilac accent (flat, no glow), waveform, phone crop, command input | wave + initial, sound orb, speech path, pulse ring | fluid, intimate |
| Cultural / experimental | music, creative tools, events | halftone, CRT, analog print, one bold accent, poster panels, unexpected crops | custom wordmark, icon with attitude, print-inspired mark | memorable, still controlled |

Light editorial and luxury modes drift toward the "named look" (cream, serif, terracotta). Use them only when the strategy earns it, and pick a hue other than terracotta unless that is the brand (the Floor).

## 6. Discipline

**Text.** Very little, large enough to render. Allowed: brand name, one tagline, one URL, one command, 2–5 section labels in sentence case, short UI chips. Never: paragraphs, tiny fake body copy, lorem ipsum, long menus, tracked all-caps labels, invented metrics or customer names. Taglines are short and specific ("Nothing random.", "On guard.", "Build better."), never buzzword soup or inspirational fluff.

**Image.** Cinematic landscapes, dusk skies, halftone clouds, CRT scenes, dark product close-ups, dramatic object crops, textured paper, moody architecture. Never generic stock people, office photos, cliché robots or busy scenes. Images match the palette and the metaphor.

**Mockups are identity applications, not feature demos.** Minimal and believable: app header, URL field, terminal, app icon, phone corner crop, card stack, badge, folder, input bar, product label. No data-heavy fake dashboards, glossy device stacks or icon overload. For HTML boards, build UI fragments with the `showcase.md` kit, not hand-drawn chrome.

**Color.** One dominant palette: base + primary accent + optional secondary accent + tinted neutrals. Accents repeat across panels; one accent can carry the whole system. Example palettes:

| Palette | Fits |
|---|---|
| black + cyan + muted coral | developer tools |
| black + red + cream + blue | operator, media |
| forest green + lime + fog gray | calm systems, climate |
| navy + white + steel | security, infra |
| ivory + deep blue + red + gold | compliance, editorial |
| black + amber + red | operator, gaming |
| charcoal + white + pale blue | quiet SaaS |
| black + lilac + soft violet | voice, music (never as AI shorthand) |

**Detail language** (sparingly; detail should reward looking closer): small page numbers, tiny footer labels, alignment marks, construction lines, crosshair grids, thin rules, image masks, low-opacity grain or halftone, one accent chip, one strong icon state. No single highlighted word in a headline (the Floor).

## 7. Anti-generic rules

Everything in the Floor's anti-generic list (SKILL.md §3) applies to boards too. Brand-specific additions: no random floating icons, startup gradients, meaningless blobs, messy collages, fake tiny UI, inconsistent marks, more than 4 colors, cheap neon, stock-template boards, corporate slide layouts, soulless SaaS dashboards. When in doubt, make it quieter, sharper and more intentional.

## 8. Output

Choose by available tooling, and say which one in one line.

**A. Image-generation tool available.** Fill this template internally, pass the canvas size to the tool's size controls, and report the actual output size.
```
Create a premium brand-kit overview image for "[BRAND NAME]".
Brand strategy:
- identity mode: [create from scratch / build on existing brand / requested refresh]
- existing assets: [supplied elements to preserve, or none]
- category / audience / personality: [traits] / core metaphor: [metaphor]
- logo: [supplied logo to reuse, or new mark: method + one-line idea]
Canvas: [requested W×H, ratio or orientation; otherwise 4:3 or 16:10]
Layout: [3×3 / 2×3 / custom] grid on a [dark/light] presentation canvas, strong gutters, clean alignment, generous negative space.
Panels: [list from §4 in order]
Visual mode: [mode]   Palette: [base, accent(s), neutrals as named hex]
Style: premium, sparse, cinematic, intentional, brand-guidelines deck, no clutter, no copied logos; reuse supplied brand assets.
Typography: readable, minimal, high hierarchy, no tiny fake text, sentence-case labels.
Logo: [reuse supplied logo without redesign / create a simple, symbolic, ownable mark]; repeat it consistently across panels.
```
Learn rhythm, grid, spacing, type scale, density, logo placement, text amount and accent logic from references; never copy their logo, name, composition, slogan or unique assets.

**B. No image tool: build the board as one HTML page** (or SVG). CSS grid of panels with `minmax(0, 1fr)` tracks and one gap token; brand tokens in `:root` from §9; the mark as inline SVG with `currentColor`; real fonts loaded; every Floor rule applies. Render it, screenshot at 1440, and review it with fresh eyes (SKILL.md §2 step 7).

**C. Written brief** when the user only wants direction: strategy block, 3 logo directions (method, rationale, sketch description), visual mode, palette table, type pairing, panel plan, then the token sheet.

## 9. Brand token sheet

The handoff artifact between brand and code, modeled on brand-guidelines: named roles, exact values, fonts with fallbacks, and application rules. Write it as `brand-tokens.md` (or the Colors/Typography sections of a DESIGN.md).

```md
# [Brand] token sheet

## Color
| Role | Name | Token | Value (OKLCH / hex) | Use | Pair, contrast |
|---|---|---|---|---|---|
| Base | Ink | --ink | oklch(0.21 0.01 250) / #1a1d21 | primary text, dark surfaces | on Canvas 15.9:1 |
| Base | Canvas | --canvas | oklch(0.98 0.004 250) / #f7f8fa | light backgrounds, text on dark | |
| Neutral | Line | --line | oklch(0.90 0.006 250) | decorative hairlines | n/a |
| Neutral | Line strong | --line-strong | oklch(0.68 0.01 250) | input borders, icons | on Canvas ≥3:1 |
| Neutral | Muted | --muted-ink | oklch(0.50 0.012 250) | secondary text | on Canvas 5.2:1 |
| Accent | Signal | --accent | oklch(0.62 0.15 200) | primary actions, one highlight per view | with --accent-ink |
| Accent | Signal ink | --accent-ink | oklch(0.99 0.01 200) | text on accent | on Signal ≥4.5:1 |
| Accent (opt.) | Second | --accent-2 | … | charts, illustration only | |

## Type
| Role | Family | Fallback stack | Applies at | Weights | Tracking / leading |
|---|---|---|---|---|---|
| Heading | [display face] | Georgia, serif | ≥24px | 500 | −0.02em / 1.1 |
| Body | [text face] | system-ui, sans-serif | <24px | 400, 500 | 0 / 1.55 |
| Mono (opt.) | [mono] | ui-monospace, monospace | code, commands | 400 | 0 |

## Shape and space
Radius steps · spacing base (4px house scale) · elevation tiers or "hairline only".

## Logo
Files (SVG mark, wordmark, lockup; light and dark) · minimum size (16px mark) · clear space (≥ the mark's x-height) · don'ts.

## Application rules
- Pick text color from the background (Ink on light, Canvas on dark); keep the hierarchy.
- Non-text shapes and chart series use accents in a fixed order: [accent → accent-2 → neutral].
- One accent covers <5% of any view.
```

Fill contrast from measurement, not estimate: body pairs ≥4.5:1, lines, icons and large text ≥3:1. Neutrals are tinted 0.005–0.015 chroma toward the anchor hue; no pure #000 or #fff. At most two families (SKILL.md §4).

**Example sheet: Anthropic brand-guidelines.** Use only for Anthropic-branded work. On any other brand this *is* the named look the Floor warns against.

| Role | Name | Hex | Use |
|---|---|---|---|
| Main | Dark | `#141413` | primary text, dark backgrounds |
| Main | Light | `#faf9f5` | light backgrounds, text on dark |
| Main | Mid gray | `#b0aea5` | secondary elements |
| Main | Light gray | `#e8e6dc` | subtle backgrounds |
| Accent | Orange | `#d97757` | primary accent |
| Accent | Blue | `#6a9bcc` | secondary accent |
| Accent | Green | `#788c5d` | tertiary accent |

Type: headings Poppins (Arial fallback) at 24pt and up; body Lora (Georgia fallback). Non-text shapes cycle orange → blue → green.

## 10. Pipeline to a themed app

1. **brandkit** (§1–§8): strategy, logo direction, visual mode, palette, board. Get the user's pick.
2. **Token sheet** (§9): exact roles, values, fonts, measured contrast.
3. **DESIGN.md**: frontmatter `colors`, `typography`, `rounded`, `spacing`, `components`; prose sections Overview, Colors, Typography, Layout, Elevation, Shapes, Components, Do's and Don'ts, Responsive, Known Gaps. Copy token-sheet values verbatim; turn application rules into Do's and Don'ts.
4. **Theme it**: `systems.md` §2 (style picked by geometry, role mapping, radius, elevation, fonts, type utilities, focus).
5. **Prove it**: `systems.md` §3 design-system page; contrast pairs ≥4.5:1 checked live; screenshots at 375 and 1280.
